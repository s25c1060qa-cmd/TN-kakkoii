# 人の手の動きに応じたブロック配置ロボット

## 概要

本プロジェクトは、人間の手の位置や接近方向を認識し、その情報に基づいてロボットアームがブロックを自律的に移動させるシステムの開発を目的としています。

ROS 2を基盤として、MediaPipeによる手の認識、OpenCVによる画像処理、MoveIt 2によるロボットアームの制御を組み合わせています。

従来の色識別によるブロック仕分けに加え、人間の手の動きを判断条件に取り入れることで、周囲の状況に応じた柔軟な物体配置を目指します。

## 主な機能

本システムでは、以下の動作の実現を目指しています。

### 1. 手の認識
- MediaPipeを使用して人間の手を検出
- 手の位置および侵入方向を認識

### 2. ブロックの認識
- OpenCVを使用してブロックを認識
- 赤色と青色のブロックを識別

### 3. ロボットアームの制御
- 青色のブロック：人間の手に近づける
- 赤色のブロック：人間の手から遠ざける
- 手の侵入方向に応じてブロックの移動先を変更

## システム構成

本システムは、以下の構成で動作することを想定しています。

1. RealSense D435で画像情報を取得
2. MediaPipeとOpenCVで手やブロックを認識
3. ROS 2のトピック通信で認識結果を送信
4. MoveIt 2でロボットアームの軌道を計画
5. CRANE-X7でブロックを移動
